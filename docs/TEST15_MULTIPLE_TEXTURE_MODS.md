# Test15: multiple PNG texture packs

APK versionCode50 / 0.1.2-test15. Performance work is paused. All twelve native libraries are reused byte-for-byte from Test14; the native core banner remains Test13/code48.

Importing a supported PNG ZIP now adds a separate pack instead of replacing the previous one. Settings > Game & files > Manage texture mods lists packs in descending priority with their name, enabled status and source texture count. Select a pack to enable/disable it, give it highest priority, or remove it (with confirmation). The global texture switch remains available. New imports start enabled with highest priority and enable the global switch, preserving the previous import behavior. Changes apply to the next game session; changes are blocked while importing or while the runtime is running.

The manager stores immutable extracted packs in private `texture-mods/<UUID>` directories, plus an ordered, atomically replaced properties index. It builds the native loader's existing texture directory from the enabled packs. A higher priority pack owns overlapping texture hashes, including differing filenames for the same hash, because the native material map uses hashes. Nonoverlapping textures from lower priority packs remain. Disabling/removing a pack regenerates the overlay from retained originals. Duplicate display names are allowed; identity is independent of filenames. Removing a pack does not remove other packs or saves.

Legacy single-pack installation is migrated on startup without changing its global toggle preference. Startup recovers the derived overlay from the authoritative index after process death, and removes abandoned staging/obsolete overlay folders. Extraction limits, traversal rejection, PNG header/dimension checks, unsupported-format rejection, and source save/export behavior are retained. Per-file hard links avoid duplicating source pixels in the overlay when supported; otherwise files are copied. Index commit failure restores the prior overlay. No game bytes, CIA files, crypto configuration or signing inputs enter the source archive.

Scope remains legacy Citra/Azahar PNG texture ZIP packs. This does not add support for code patches, RomFS replacements, or arbitrary mod formats. Combining texture packs does not guarantee performance; large textures can increase RAM/GPU use.

Validation: `python3 android/tests/run_texture_mods_test.py` runs synthetic migration/coexistence/hash-priority, disable/re-enable, removal restoration, restart recovery (including a missing overlay), all-disabled persistence, empty-catalog behavior, invalid ZIP preservation, failed index commit rollback and failed staging preservation. Existing save roundtrip/security and four-language tests run too. Packaging checks version/package/signing continuity, ARM64/16KiB compatibility, unchanged native libraries/JNI and embedded source equality. Phone gameplay and real-pack testing remain pending. No GitHub publication is authorized.
